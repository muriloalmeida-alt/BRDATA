# Touchline · Primeiro Contrato — projeto para Claude

Comece por [LEIA_PRIMEIRO_CLAUDE.md](LEIA_PRIMEIRO_CLAUDE.md). Esse briefing governa a implementação visual e completa [PROJETO.md](PROJETO.md) e [CATALOGO.md](CATALOGO.md).

- `pranchas/` — quatro pranchas atualizadas, com 16 telas mapeadas no briefing.
- `touchline/` — logo e ícone originais, tokens e fontes locais com licença.
- `catalogo/` — base de 795 clubes de 34 ligas/divisões em 11 países e índice de escudos do catálogo.
- `fundos/` — fundos verticais e seus arquivos de referência. Consulte [FUNDOS.md](FUNDOS.md).

A cobertura mundial continua como requisito de desenvolvimento. O snapshot inicial cobre os países já disponíveis no Touchline.
